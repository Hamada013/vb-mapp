# Sound script for the touch games

Generated by `node scripts/build-sound-script.cjs` from `assets/games-data.js`. Do not edit by hand. Change the clips there and run the script again.

**292 clips.** Record each line in your own voice, then save it as `audio/NNN.mp3` (for example `audio/101.mp3`) in the repository and run `npm run build` so it works offline. A game plays a clip at the start of each trial when the file exists. When there is no file it stays silent: the line appears on screen and the assessor says it, and the speaker button replays the recording.

Recording tips: one short, clear sentence per file, mono MP3, a quiet room, and no more than ¼ s of silence at each end. Numbers never change once given: new clips are added at the end of their range.
